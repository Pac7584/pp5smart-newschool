# PP5Smart

ระบบงานทะเบียนวัดผลสำหรับโรงเรียนระดับประถมศึกษาและมัธยมศึกษาตอนต้น (ป.1–ม.3)
บันทึกเวลาเรียน คะแนน ผลประเมิน และพิมพ์ ปพ.5 / ปพ.6 ทำงานบน Supabase + Vercel (ใช้ฟรีได้)

- แจกฟรีภายใต้สัญญาอนุญาต **GPL-3.0** (ดู `LICENSE`)
- ชุดนี้ **ไม่มีข้อมูลนักเรียน ครู หรือโรงเรียนใด** ทุกโรงเรียนมีฐานข้อมูลของตัวเองแยกกัน
- **วิธีติดตั้ง: [docs/ติดตั้ง.md](docs/ติดตั้ง.md)** (ประมาณ 45–60 นาที)
- รายวิชาต้นแบบสำหรับนำเข้า: `catalog/` (ฉบับ ม.1–ม.3 เป็นฉบับร่าง ให้ครูวิชาการตรวจก่อนใช้)

## ทำอะไรได้บ้าง
- ประถม ตัดสินผลรายปี / ม.ต้น ตัดสินผลรายภาค (ตั้งค่า "ระดับชั้นที่เปิดสอน")
- เวลาเรียนรายวัน/รายเดือน คะแนนเก็บ 9 ครั้ง + ปลายภาค ผลประเมินอ่าน คิดวิเคราะห์ เขียน คุณลักษณะ สมรรถนะ กิจกรรม
- ปพ.5 ปพ.6 รายงานหน้าเดียว สรุปผลรายชั้น ไฟล์นำเข้า SchoolMIS
- นำเข้ารายชื่อจาก DMC บัญชีครูและผู้ปกครอง หน้าผู้ปกครอง (แจ้งเตือน LINE ไม่บังคับ)
- เลื่อนชั้น/ปิดปีการศึกษา พร้อมย้อนกลับได้ และสำรองข้อมูลจากในโปรแกรม

## โครงสร้าง
- `index.html`, `js/`, `css/`, `assets/`, `vendor/` — ตัวเว็บ
- `js/app-config.js` — ไฟล์เดียวที่แต่ละโรงเรียนต้องแก้
- `supabase/install/install.sql` — ติดตั้งฐานข้อมูลทั้งหมดในครั้งเดียว
- `supabase/functions/` — Edge Functions: `admin-users` (บัญชีผู้ใช้) และ `line-notify` (LINE ไม่บังคับ)
- `catalog/` — รายวิชาต้นแบบ
- `tools/dev-server.mjs` — เปิดเว็บทดสอบในเครื่อง: `node tools/dev-server.mjs`
