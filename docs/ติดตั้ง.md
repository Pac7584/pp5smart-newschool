# คู่มือติดตั้ง PP5Smart สำหรับโรงเรียนใหม่

ใช้เวลาประมาณ 45–60 นาที ไม่ต้องเขียนโปรแกรม ทุกอย่างใช้ฟรี
คู่มือนี้ทดสอบกับการติดตั้งจริงบนโปรเจกต์ Supabase ใหม่แล้ว (ตุลาคม 2569)

## สิ่งที่ต้องเตรียม

| สิ่งที่ต้องมี | ใช้ทำอะไร |
|---|---|
| อีเมล 1 ชื่อสำหรับโรงเรียน (Gmail หรืออีเมลโรงเรียน) | สมัคร Supabase และ GitHub / Vercel |
| บัญชี **Supabase** (ฟรี) | ฐานข้อมูลของโรงเรียน |
| บัญชี **GitHub** และ **Vercel** (ฟรี) | เก็บโปรแกรมและเปิดเว็บ |
| ไฟล์ส่งออกรายชื่อนักเรียนจาก **DMC** (.xlsx / .csv) | นำเข้ารายชื่อนักเรียน |

> ⚠️ แผนฟรีของ Supabase สร้างได้ **2 โปรเจกต์ต่อบัญชี** ถ้าบัญชีเดิมใช้ครบแล้ว ให้สมัครด้วยอีเมลใหม่ของโรงเรียน

> 🔒 **ห้าม** นำ `service_role` key, Secret key (`sb_secret_...`) หรือรหัสผ่านฐานข้อมูล ไปใส่ในไฟล์ใดของเว็บ หรือส่งให้ใคร

## ส่วนที่ 1 — ฐานข้อมูล (Supabase)

### ขั้น 1: สร้างโปรเจกต์
1. เข้า [supabase.com](https://supabase.com) > **Sign in** > **New project**
2. ตั้งชื่อ เช่น `pp5-ชื่อโรงเรียน` เลือก Region **Singapore** (หรือใกล้ที่สุด)
3. ตั้ง **Database Password** แล้ว **จดเก็บไว้เอง** (ไม่ต้องใช้ในเว็บ)
4. กด **Create new project** รอ 1–2 นาทีจนสถานะเป็น Healthy

### ขั้น 2: ติดตั้งฐานข้อมูล (ครั้งเดียว)
1. เมนูซ้าย **SQL Editor** (ไอคอน `>_`) > **New query**
2. เปิดไฟล์ `supabase/install/install.sql` คัดลอก **ทั้งไฟล์** มาวาง
3. **ตรวจชื่อโปรเจกต์ที่มุมซ้ายบนให้ถูก** แล้วกด **Run**
4. ต้องขึ้น **Success. No rows returned**

> ถ้ามีข้อผิดพลาด ทุกอย่างจะย้อนกลับเองทั้งหมด ไม่มีอะไรค้างครึ่งทาง ถ้ารันซ้ำในโปรเจกต์เดิมจะขึ้นว่ามีตารางอยู่แล้ว (already exists) — แปลว่าติดตั้งไปแล้ว ไม่ต้องทำอะไร

### ขั้น 3: ปิดการสมัครสมาชิกเอง
**Authentication** > **Sign In / Providers** (หรือ Settings) > ปิด **Allow new users to sign up**
บัญชีครูและผู้ปกครองจะสร้างจากในโปรแกรมโดยผู้ดูแลเท่านั้น

### ขั้น 4: สร้างผู้ดูแลระบบคนแรก
1. **Authentication** > **Users** > **Add user** > **Create new user**
2. ใส่อีเมลผู้ดูแล ตั้งรหัสผ่าน ติ๊ก **Auto Confirm User** > **Create user**
3. กลับไป **SQL Editor** > New query แล้วรัน (เปลี่ยนอีเมลให้ตรง):
   ```sql
   select public.pp5_install_make_admin('อีเมลผู้ดูแล');
   ```
4. ต้องขึ้น **ตั้งเป็นผู้ดูแลระบบแล้ว: ...**

> ถ้าขึ้น "ไม่พบผู้ใช้ ... ใน Authentication > Users" แปลว่ายังไม่ได้ทำข้อ 1–2 หรืออีเมลพิมพ์ไม่ตรง

### ขั้น 5: ติดตั้งระบบจัดการบัญชีผู้ใช้ (Edge Function `admin-users`)
จำเป็นสำหรับการสร้างบัญชีครูและผู้ปกครองในเมนู **ผู้ใช้และสิทธิ์**
1. เมนูซ้าย **Edge Functions** > **Deploy a new function** > **Via Editor**
2. ตั้งชื่อ function ว่า `admin-users` (ต้องตรงทุกตัวอักษร)
3. ลบโค้ดตัวอย่างออก แล้ววางโค้ดจากไฟล์ `supabase/functions/admin-users/index.ts` ทั้งไฟล์ > **Deploy**
4. เปิด function `admin-users` > **Details / Settings** > ปิด **Verify JWT** (บางหน้าจอเขียนว่า *Verify JWT with legacy secret*) > Save
   — ปลอดภัย เพราะโค้ดตรวจเองว่าผู้เรียกต้องเป็นผู้ดูแลที่ยังใช้งานอยู่

### ขั้น 6: คัดลอกค่าสำหรับเว็บ
**Project Settings** (เฟือง) > **API Keys** (และ **Data API**) คัดลอก 2 ค่า:
- **Project URL** เช่น `https://abcdefghijklmnop.supabase.co`
- **Publishable key** (`sb_publishable_...`) หรือในแท็บ Legacy คือ **anon public** (`eyJ...`) — ใช้ได้ทั้งสองแบบ

## ส่วนที่ 2 — เว็บไซต์ (GitHub + Vercel)

### ขั้น 7: ตั้งค่าเว็บของโรงเรียน
1. ที่หน้า GitHub ของโปรแกรม กด **Fork** เพื่อคัดลอกเป็นของโรงเรียน
2. ใน repo ที่ fork แล้ว เปิดไฟล์ `js/app-config.js` > ไอคอนดินสอ (Edit)
3. แก้ 2–3 บรรทัดนี้ แล้วกด **Commit changes**
   ```js
   supabaseUrl: 'https://abcdefghijklmnop.supabase.co',
   supabaseAnonKey: 'sb_publishable_xxxxxxxxxxxx',
   siteUrl: '',   // ใส่ภายหลังเมื่อมีโดเมนของโรงเรียน เช่น 'https://pp5.your-school.ac.th'
   ```
   ไฟล์นี้เป็นไฟล์เดียวที่ต้องแก้ ค่าในไฟล์เปิดเผยได้ (สิทธิ์จริงคุมด้วยฐานข้อมูล)

### ขั้น 8: เปิดเว็บด้วย Vercel
1. เข้า [vercel.com](https://vercel.com) > **Sign up with GitHub**
2. **Add New** > **Project** > เลือก repo ที่ fork มา > **Deploy** (ไม่ต้องตั้งค่าอื่น)
3. ได้ที่อยู่เว็บ เช่น `https://pp5-xxxx.vercel.app`
4. (ไม่บังคับ) ผูกโดเมนของโรงเรียนใน Vercel > Settings > Domains แล้วใส่ที่อยู่นั้นใน `siteUrl`

![หน้าเข้าสู่ระบบหลังติดตั้ง](images/01-login.png)

ถ้าหน้าเข้าสู่ระบบขึ้น "ชื่อโรงเรียน (แก้ในหน้าตั้งค่าระบบกลาง)" แปลว่าเว็บเชื่อมฐานข้อมูลได้แล้ว
ถ้าขึ้น "ไม่สามารถโหลดข้อมูลโรงเรียนได้" ให้ตรวจ `supabaseUrl` / `supabaseAnonKey` ในขั้น 7

## ส่วนที่ 3 — เริ่มใช้งาน (ทำในโปรแกรม)

### ขั้น 9: เข้าสู่ระบบและตั้งค่าโรงเรียน
เข้าสู่ระบบด้วยอีเมลผู้ดูแล (ขั้น 4) แล้วไปที่ **ตั้งค่าและดูแลระบบ > ตั้งค่าระบบกลาง**
- **ข้อมูลทั่วไป**: ชื่อโรงเรียน ที่อยู่ สังกัด ปีการศึกษา ภาคเรียน ผู้อำนวยการ หัวหน้าวิชาการ
- **ระดับชั้นที่เปิดสอน**: ประถม (ป.1–ป.6) หรือ ป.1–ม.3 สำหรับโรงเรียนขยายโอกาส
- **หน้าตาโรงเรียน**: สีธีม คำขวัญ รูปแบนเนอร์
- **โลโก้และตราโรงเรียน**: เมนูตั้งค่าและดูแลระบบ > โลโก้และตราโรงเรียน
- **ลายเซ็น**: ส่วนจัดการลายเซ็นในหน้าเดียวกัน (ไม่บังคับ)

![ตั้งค่าระบบกลาง](images/03-settings.png)

### ขั้น 10: นำเข้ารายวิชา
**ตั้งค่าและดูแลระบบ > รายวิชาและหลักสูตร** > ปุ่ม **นำเข้า CSV/Excel** > เลือกไฟล์ในโฟลเดอร์ `catalog/`
- `รายวิชาต้นแบบ_ป1-ป6.xlsx` — ป.1–ป.6 (90 รายการ รวมกิจกรรม)
- `รายวิชา_ม1-ม3_ฉบับร่าง.xlsx` — ม.1–ม.3 วิชาพื้นฐานและกิจกรรม แยกภาค 1 / ภาค 2 (84 รายการ, **ฉบับร่าง ให้ครูวิชาการตรวจก่อน**)

หลังนำเข้า ปรับชั่วโมง ชื่อชุมนุม วิชาเพิ่มเติม และครูผู้สอนให้ตรงหลักสูตรสถานศึกษา ด้วยปุ่ม ✏️ ท้ายแถว
หลักสำคัญ:
- **ม.1–ม.3 ตัดสินผลรายภาค**: ทุกวิชาต้องระบุ **ภาคเรียน 1 หรือ 2** กิจกรรมก็แยกภาคเช่นกัน (เช่น "แนะแนว 1" ภาค 1 / "แนะแนว 2" ภาค 2)
- ชื่อวิชาในชั้นเดียวกันห้ามซ้ำ (ม.ต้นใช้ "ภาษาไทย 1" / "ภาษาไทย 2")
- หน่วยกิต = ชั่วโมง ÷ 40 โปรแกรมคิดให้เอง

### ขั้น 11: นำเข้ารายชื่อนักเรียนจาก DMC

## ดูแลระบบระยะยาว

- **สำรองข้อมูลสม่ำเสมอ**: Supabase แผนฟรีไม่มีสำรองอัตโนมัติ ใช้ปุ่ม **สำรองตอนนี้** ที่หน้าหลัก (หรือ ตั้งค่าระบบกลาง > สำรองข้อมูล) อย่างน้อยเดือนละครั้งและก่อนปิดปีการศึกษา เก็บไฟล์ไว้ในที่ปลอดภัย
- **โปรเจกต์ฟรีจะหยุดพักเองเมื่อไม่มีใครใช้งาน 7 วัน** ดูหัวข้อ [ช่วงปิดเทอม](#ช่วงปิดเทอม) ด้านล่าง
- **ปิดปีการศึกษา**: ตั้งค่าระบบกลาง > เปลี่ยนปีการศึกษา (ระบบเลื่อนชั้นให้ ป.6 / ม.3 จำหน่ายจบ) — สำรองข้อมูลก่อนเสมอ
- **ปรับปรุงเวอร์ชันโปรแกรม**: ที่ repo ของโรงเรียนบน GitHub กด **Sync fork** — Vercel จะเปิดเว็บเวอร์ชันใหม่ให้เอง ถ้าเวอร์ชันใหม่ต้องแก้ฐานข้อมูล จะมีไฟล์ SQL และคำอธิบายแนบไว้ในหน้าประกาศเวอร์ชัน

## ช่วงปิดเทอม

Supabase แผนฟรีจะ **หยุดพักฐานข้อมูลเมื่อไม่มีใครเข้าเว็บเลย 7 วันติดต่อกัน** (ตัวเว็บบน Vercel ไม่หยุด)
- ถ้ายังมีคนเข้าใช้บ้าง เช่น ผู้ปกครองดูผลการเรียน หรือครูเข้ามาทำงาน ระบบทำงานตามปกติ
- ระหว่างที่หยุดพัก **ข้อมูลไม่หาย** แต่ทุกคนจะเข้าระบบไม่ได้ (หน้าเข้าสู่ระบบขึ้นว่าโหลดข้อมูลโรงเรียนไม่ได้)

**สิ่งที่ผู้ดูแลระบบควรทำ**
1. **ก่อนปิดเทอม**: กด **สำรองตอนนี้** ที่หน้าหลัก แล้วเก็บไฟล์ไว้ในที่ปลอดภัย
2. **ระหว่างปิดเทอม**: เข้าเว็บของโรงเรียน **สัปดาห์ละครั้ง** (เข้าสู่ระบบแล้วเปิดหน้าหลักก็พอ) แนะนำตั้งเตือนในปฏิทินมือถือ
3. **ถ้าหยุดพักไปแล้ว** เปิดคืนได้เอง:
   1. เข้า [supabase.com](https://supabase.com) ด้วยอีเมลของโรงเรียน
   2. เลือกโปรเจกต์ที่ขึ้นว่า **Paused**
   3. กด **Restore project** แล้วรอประมาณ 2–5 นาที จากนั้นเปิดเว็บใหม่
4. **อย่าปล่อยให้หยุดพักนานหลายเดือน**: ตามเงื่อนไขปัจจุบันของ Supabase โปรเจกต์ที่หยุดพักนานเกินประมาณ 90 วันจะเปิดคืนจากหน้าเว็บไม่ได้ (เงื่อนไขนี้ Supabase เปลี่ยนได้ ตรวจในหน้าโปรเจกต์) จึงควรสำรองข้อมูลไว้เสมอ

## ส่วนเสริม (ไม่บังคับ)
- **รูปนักเรียน**: ใช้ได้ทันที (รายชื่อนักเรียน > ปุ่มรูปนักเรียน)
- **แจ้งเตือนผู้ปกครองทาง LINE**: ต้องมี LINE Official Account และติดตั้ง Edge Function `line-notify` (คู่มือแยก)
- **นำเข้าคะแนนจากระบบห้องสอบดิจิทัล**: ตั้งค่า `examImport` ใน `js/app-config.js` (ไม่ตั้ง = ไม่มีปุ่ม)

## ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| สร้างโปรเจกต์ Supabase ไม่ได้ ขึ้นว่าเกินจำนวนฟรี | บัญชีมีโปรเจกต์ฟรีครบ 2 แล้ว สมัครด้วยอีเมลใหม่ของโรงเรียน |
| `pp5_install_make_admin` ขึ้น "ไม่พบผู้ใช้" | สร้างผู้ใช้ใน Authentication > Users ก่อน (ขั้น 4) |
| หน้าเข้าสู่ระบบขึ้น "ไม่สามารถโหลดข้อมูลโรงเรียนได้" | ถ้าเคยใช้ได้แล้วจู่ ๆ เป็น: โปรเจกต์ถูกหยุดพักเพราะไม่มีใครใช้ 7 วัน ให้ **Restore project** ตาม [ช่วงปิดเทอม](#ช่วงปิดเทอม) — ถ้าเป็นตั้งแต่ติดตั้ง: `supabaseUrl` / `supabaseAnonKey` ใน `js/app-config.js` ไม่ถูกต้อง |
| เข้าสู่ระบบได้แต่เมนูผู้ดูแลไม่ขึ้น | ยังไม่ได้รัน `pp5_install_make_admin` กับอีเมลนั้น |
| เพิ่มบัญชีครูไม่ได้ | ยังไม่ได้ติดตั้ง `admin-users` (ขั้น 5) หรือยังไม่ได้ปิด Verify JWT |
| นำเข้ารายวิชา ม. แล้วขึ้น "ต้องระบุภาคเรียน" | ไฟล์ต้องมีคอลัมน์ "ภาคเรียน" (1 หรือ 2) ใช้ไฟล์ใน `catalog/` เป็นแม่แบบ |
